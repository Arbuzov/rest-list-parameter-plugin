An optional Java regular expression applied to every display value (what the user sees in the dropdown). The actual parameter value passed to the build is never modified by this option.
Use it together with Display Decoration Replacement to:
  • Strip a prefix (pattern ^v, replacement empty) → v10.7.7 → 10.7.7
  • Append a suffix (pattern $, replacement  (stable)) → 10.7.7 → 10.7.7 (stable)
  • Reformat with capture groups (pattern ^v(\d+\.\d+\.\d+).*, replacement Release $1)
Leave empty to keep display values unchanged. An invalid pattern is logged as a warning and the original display value is shown.
